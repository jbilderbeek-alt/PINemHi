Build this app just for fun and learning vibe-coding.
I play on my Virtal Pinball cabinet daily and use PINemHi to track scores and do some competition.
I only didn't like checking the website on my phone so I created the app and widget. 
During development I came up with some nice additions to the website like a timer in the different competitions and high-lighting of your own username. 

Please let me know if you find any bugs or have ideas for improving this app.
