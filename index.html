Info & Version History

PINEMHI App and Widget for Android, webapp for iOS By Jochen Bilderbeek, The Netherlands V1.5 (November 2026) - WebApp for iOS live! - Added chat to each tab separately - Added option to create a profile with some personal information - Added options to edit or delete chats (Android: hold message for options, webapp: tap the pencil or cross icon) V1.4 (November 2026) - Added more notification options to remind you to compete (Android only) - Added a chat function! V1.3 (November 2026) - Added the score to beat at the PIN contest. Now you can easily see what score you need to beat (a personal request) - Better looks for the app - English as default, Dutch is available (for the settings) - Changed 5 MIN to 5 Minute Mode and PIN to Closest to the pin contest - If no score is posted yet, that will be shown. - Adjusted the notification texts. - Added version history to app (tap the version text at the bottom in settings) V1.2 (November 2026) - Visual adjustments because of changes to the website - Added notifications for rank loss can be turned on/off in Settings (Android only) - Added a button for Language option in Settings - Removed the Game name from the table at Weekly Competition, 5 MIN and PIN, because the game's name is already above the scores. - Warning sign starts blinking when only 1 hour remains for that mode (app only) - Small improvements - Uploaded to VPuniverse v1.1 (October 2026) Initial release - Main info from PINemHi website in app and widget (Android only) - Settings menu for personal preferences - Created logo for app - Only available at Pinemhi.com and Tweakers.net Built this app just for fun and learning vibe-coding. I play on my Virtual Pinball cabinet daily and use PINemHi to track scores and do some competition. I only didn't like checking the website on my phone so I created the app and widget. During development I came up with some nice additions to the website like a timer in the different competitions and highlighting of your own username. Please let me know if you find any bugs or have ideas for improving this app. Contact me at: jbilderbeek@hotmail.com POSSIBLE FEATURES: - Personal best scores
